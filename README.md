# Sermones para Claude

Skill para preparar sermones adventistas en Claude Code: estudio exegético, sermón completo, tarjeta del predicador y prompt de slides. Cada cita de Elena White y cada estadística se verifica antes de entregarse; si tienes Logos, el estudio se arma con tu biblioteca.

## Instalar (Mac)

```bash
curl -fsSL https://raw.githubusercontent.com/prcontreras23/sermones-para-claude/main/instalar.sh | bash
```

Instala Claude Code si falta, copia el skill, crea tu carpeta de sermones y, si tienes Logos, conecta tu biblioteca. Se puede correr varias veces sin perder tu configuración.

## Usar

Abre la app de Claude → pestaña Code → elige tu carpeta de sermones → «prepara un sermón de Juan 3:1-21».
